# Data & Machine Learning Projects

A collection of selected projects exploring data analysis, visualization, regression, and classification with Python.

## Projects

### [Ford Cars Price Prediction](https://github.com/Moataz-Nasser/Ford-Cars-Price-Prediction)

Exploratory analysis of Ford car listings and a linear regression model for estimating car prices, with an interactive Streamlit app.

**Focus:** Data cleaning, exploratory data analysis, visualization, linear regression, Streamlit

### [Steam Games Analysis](https://github.com/Moataz-Nasser/Steam-Games-Analysis)

Analysis of Steam's 2025 games dataset, exploring game modes, genres, operating-system support, release trends, and prices.

**Focus:** Data cleaning, exploratory data analysis, visualization

### [Student Performance & Weather Classification](https://github.com/Moataz-Nasser/Student-Performance-and-Weather-Classification)

Two machine learning projects: predicting student performance with linear regression and classifying weather types with logistic regression.

**Focus:** Regression, classification, feature encoding, evaluation metrics

### [Breast Cancer Classification](https://github.com/Moataz-Nasser/Breast-Cancer-Classification)

Comparison of classification models on the Breast Cancer Wisconsin Diagnostic Dataset, including SVC, logistic regression, and random forest.

**Focus:** Classification, model comparison, feature selection, cross-validation

---

Each project repository contains its own notebook, data and project-specific documentation.
